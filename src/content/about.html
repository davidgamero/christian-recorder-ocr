What the experiments established

  • Chunks beat whole pages. GLM and DeepSeek both reached 0.52% character error on two checked pilot excerpts; Paddle reached 0.78%, fixed-chunk Tesseract 5.88%.
  • Layout matters. A failed landscape run led to separate leaves, printed-rule gutters and sloped mastheads.
  • Graphs improved throughput. Four-request decode CUDA graphs were 3.43× faster than four-request eager execution on the same test workload.

Those references were provisional and previously inspected. They do not establish corpus-wide accuracy. The original v4 edition had 435 scans with output flags. The current count also includes unresolved rerun candidates; unflagged text may still contain errors. Results, runtime & build details ↗

Targeted reprocessing

The v4 audit found 434 high-loop candidates among 60,065 chunks. An initial smaller-crop repair removed many loops, but scan review found remaining clipped columns and omissions. Passing a loop check did not prove an accurate transcription.

The v5 pass reprocessed 6,445 known-failure and multiple-warning chunks across 1,496 scans. It uses original scan pixels, tilted printed-rule cuts, crops up to 900 pixels high, and streaming loop cancellation. An early equal-width fallback was discarded after previewing a cut through text. Unresolved wide regions retain the prior text. Source footprints are preserved to avoid duplicating neighboring text; already-clipped outside edges can still need review.

Only replacements that passed automatic output and text-volume checks were selected. Other candidates retain the prior text with an unresolved flag. Original artifacts and attempts remain preserved.
